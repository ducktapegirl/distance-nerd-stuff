Toward the blanket: muted yarn and a stitch grain

Your reference blanket reads as yarn for two reasons, and neither is per-strand shading: the colors are matte and muted, and one fine stitch texture runs uniformly across every color, with the rows fully covering the surface. These four vary exactly those two things — how far the palette is pulled toward wool, and which stitch the grain imitates — on the same real 44-week window as before. The grain is a tiled SVG pattern stroked along each thread, so it lives only on yarn, never on the gaps.
