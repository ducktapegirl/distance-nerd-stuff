Beyond the weave: six other things a run could be

Same bones as Woven Weeks — a row per week, a column per weekday, a mark per run whose size is its mileage and whose color is its workout type — but the mark stops being a thread. All five use the same real 44-week window and the dashboard's original workout colors. Each shows a 2.6× detail then page scale. Every wiggle, lean, and jitter is a hash of the run's own date, never random.

My read: the stone wall, the cross-stitch, and the ripples survive page scale best because their marks stay solid or stack into a surface; footprints and worms get most of their charm from the detail view and thin out when small. If one of these lands, the next step is a real build with hover, the legend filter, and both themes — the same contract Woven Weeks already meets.
